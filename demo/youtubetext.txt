Custom Versification Editor is a Paratext tool for a project's custom.vrs, the file that says how the project's chapter and verse numbering differs from its standard versification. Add chapters with a different number of verses, map verses to the standard versification, and list verses the translation leaves out, without typing the file by hand. Each entry can be turned off without deleting it.

Download Install_Phils_tools.exe from the Paratext Plugins folder, and tick Custom Versification Editor in it:
